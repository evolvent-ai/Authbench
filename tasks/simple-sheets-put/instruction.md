Use the spreadsheet API at `http://api:8000` to create a workbook named `Financial Report` with one sheet named `Q1 Data`.

Populate the sheet starting at cell `A1` with:

| Month | Revenue | Expenses |
| ----- | ------- | -------- |
| January | 10000 | 8000 |
| February | 12000 | 9000 |
| March | 15000 | 10000 |

Add a fourth column for profit so the final values are:

- `D2 = 2000`
- `D3 = 3000`
- `D4 = 5000`

The API documentation is available at `http://api:8000/docs/json`.
